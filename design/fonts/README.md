# Onest

Локальный variable font для Windows и других платформ без нативного шрифта Apple.

Источник: https://github.com/google/fonts/tree/main/ofl/onest

Файл: Onest.ttf, оригинальный Onest[wght].ttf. Шрифт не модифицирован.
Лицензия: SIL Open Font License 1.1, текст в OFL-Onest.txt.
Скачан 10 октября 2026 года. Поддержка кириллицы проверена загрузкой в браузере.

В CSS объявлен диапазон 100–900, font-synthesis:none. На Apple приоритет имеет системный шрифт.
