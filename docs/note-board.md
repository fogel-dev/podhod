# Доска заметок и элементы управления

Требования пользователя от 10 октября 2026: несколько заметок на день, миниатюры стикеров, создание и редактирование в анимированной нижней панели. Миграция 010 сохраняет записи, снимая уникальность пары пользователя и даты. GET дня возвращает notes (до 100), старое note сохраняется как первая заметка для совместимости. PUT/DELETE /days/{date}/notes/{id} работают с отдельной записью, If-Match, идемпотентностью и проверкой владельца. Старые маршруты работают с первой заметкой.

Редактор предупреждает при закрытии несохранённого текста, сохраняет текст при ошибке и позволяет загрузить актуальную версию при конфликте. Заметки остаются приватными. Анимация появления панели отключается при prefers-reduced-motion, диалог удерживает фокус и учитывает safe-area. Поле не растягивается вручную.

Другие правки: отступы между вертикальными кнопками и над возвратом к текущему месяцу; прозрачные «Назад» и «Обновить»; скрытый часовой пояс программы с сохранением зоны существующей программы; общий кастомный Select в мастере, прогрессе и истории с клавиатурной навигацией и отступом стрелки справа.

Linear не синхронизирован: подключение отсутствует среди инструментов. Требуется задача проекта «Подход» с перечисленными критериями. 10 октября 2026 пользователь разрешил коммит и пуш этих изменений.

Проверки: npm run check и git diff --check прошли; интеграционные тесты journal и database прошли на изолированной PostgreSQL. Docker-сборка и миграция 010 выполнены. В браузере проверены выбор дня мышью и клавиатурой, отступ 12 px между кнопками программы, открытие существующей заметки и создание новой без сохранения пользовательских данных. На ширине 320 px в светлой теме панель не вызывает горизонтальный скролл; фокус попадает в textarea, resize отключён. Тёмная тема также проверена.
