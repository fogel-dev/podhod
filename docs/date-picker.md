# Выбор периода программы

Запрос пользователя от 10 октября 2026: заменить системный выбор даты кастомным компонентом и изменить быстрые периоды на 4 и 8 недель.

В shared/ui/date-picker добавлен календарь в нижней панели, соответствующий существующей палитре. Поддержаны переключение месяцев, ограничения min/max, клавиатурные стрелки, Home/End, PageUp/PageDown, Enter и возврат фокуса. Компонент используется для начала, окончания и даты применения изменений программы. Новый период по умолчанию — 4 недели (28 дней включительно); существующие даты программ не изменяются. При переносе начала за окончание окончание переносится на новую дату начала.

Проверки: npm run check, Docker production-сборка; в браузере проверены выбор даты стрелками и Enter, расчёт 8 недель, недоступность окончания раньше начала и отсутствие горизонтального скролла на ширине 320 px. Проверочный черновик не сохранён.

Linear не синхронизирован: подключение отсутствует среди доступных инструментов. 10 октября 2026 пользователь разрешил коммит и пуш этих изменений.
