# Упрощение входа и регистрации

10 октября 2026: по замечаниям пользователя переключатель темы заменён на кнопку с солнцем или луной. Системная тема используется по умолчанию, кнопка переключает только светлую и тёмную темы и сохраняет выбор. Название устройства определяется автоматически без поля в формах. Минимальная длина нового пароля снижена до 8 символов, без требований к классам символов. При входе подсказки регистрации скрыты.

Linear не синхронизирован: инструменты подключения отсутствуют в текущей сессии. Требуется создать задачу в проекте «Подход», отразить изменения и результаты проверок. 10 октября 2026 пользователь разрешил коммит и пуш этих изменений.

Проверки: npm run check прошёл; сборка Docker прошла на Node 22.20.0; тесты авторизации прошли на Go 1.27.2 (интеграционные тесты без TEST_DATABASE_URL пропускаются).

Дополнительные правки по шести комментариям браузера: отступ 16 px над ссылкой программы; заметка как карточка с textarea без resize; выбор фото через кнопку со скрытым файловым input; удаление фото крестиком справа сверху; блок часового пояса убран из настроек; переключатель темы перенесён в общую шапку рядом с настройками. Серверное хранение часового пояса сохранено для календаря и напоминаний.

Проверки этой итерации: npm run check и Docker-сборка прошли. В браузере проверены главная, настройки и дневник с существующими фотографиями, обе темы и ширина 320 px без горизонтального переполнения. Удаление фотографий и сохранение заметки не выполнялись, чтобы не менять пользовательские записи. Linear по-прежнему не синхронизирован.
