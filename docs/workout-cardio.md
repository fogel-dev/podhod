# Кардио в тренировке

Запрос пользователя 11 октября 2026: необязательная отметка о кардио на странице тренировки с видом активности и длительностью.

Сценарий: в общем списке тренировки рядом с временем расположен блок «Кардио». «Отметить кардио» открывает существующий BottomSheet с полями «Вид кардио» и «Время, мин». Отсутствие отметки не препятствует завершению тренировки. Активность — свободный текст до 120 символов, время — целые минуты от 1 до 1440. До завершения можно изменить или убрать отметку. После завершения сведения доступны только для просмотра. Они не добавляются к силовому объему, повторениям и времени отдыха и не меняют длительность тренировки по timestamp.

Миграция 013 добавляет nullable-поля к личной тренировке без изменения существующих записей. Команда set_cardio использует общую версию агрегата, commandId и квитанции повторной отправки. Явный cardio=null снимает отметку. Сервер и БД запрещают изменение кардио завершенной тренировки. Другой пользователь не может читать или изменять эти данные. Исправления силового результата сохраняют кардио без изменений. Клиент сообщает об ошибке сохранения и позволяет повторить тот же запрос; фоновая офлайн-синхронизация не заявляется.

Linear не синхронизирован: подключение отсутствует среди доступных инструментов. Для последующей задачи проекта «Подход»: приемка — необязательность отметки, сохранение и повторное чтение, изменение/снятие до завершения, отображение в истории, приватность, валидация и защита повторных команд и конфликтов версий.

11 октября 2026 пользователь разрешил коммит и пуш изменений. Номер Linear отсутствует из-за недоступного подключения; вымышленный идентификатор не используется.

Проверки: npm run check и Docker production-сборка прошли; миграция 013 применена локально. Целевые Go-тесты на изолированном PostgreSQL проверяют добавление, снятие, повторное чтение, границы и структуру входных данных, идемпотентность, конфликт версий, запрет доступа другого пользователя и неизменность после завершения. Браузерный тест использовал настоящие React и API на отдельной базе: сохранение, перезагрузка, снятие, повторное добавление и завершение прошли; проверены обе темы и ширина 320 px. Временная база, серверы и тестовый файл удалены после проверки, пользовательские данные не затрагивались. Полный пакет workouts не прогонялся из-за ранее известного сбоя TestSavedProgramSnapshotAndReplacementProtection (shared-library.md).
