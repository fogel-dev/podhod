# EGO-45: правки интерфейса по аннотациям

11 октября 2026. Результат принят пользователем, коммит и пуш разрешены сообщением «запуш».

## Изменения

- Заметки: компактные жёлтые стикеры высотой 112px, четыре строки превью и небольшой загнутый угол; полный текст остаётся в редакторе.
- Главная: карточка восстановления с названием и действием, на 320px действие переносится под заголовок.
- Программа: отступ 24px перед существующими программами, убрана строка часового пояса из проверки (сам пояс остаётся частью модели и API).
- Редактор: заголовок «Подход» получил отдельную колонку 48px; новые подходы содержат 12–15 повторений, существующие значения сохраняются.
- При переходе от выбора дней к упражнениям открывается первый день по порядку недели.
- Библиотека: несколько чекбоксов и общее действие добавления; выбранные упражнения сохраняются при поиске. Учитывается лимит 100 упражнений в дне.
- Под каждой строкой подхода есть «Повторить во всех»: копируются вес и диапазон повторений, идентификаторы и порядок сохраняются; затем любую строку можно изменить отдельно.
- Загрузки: структурные скелетоны для главной, календаря, дня, редактора, прогресса, тренировки, библиотек, подключения и устройств. Запрос начинается сразу, результат/ошибка отображаются после минимум 400ms. Смена маршрута отменяет запрос и освобождает таймер; старые данные не показываются под новым ключом. При prefers-reduced-motion пульсация отключена.

## Проверки

- `npm run check`: API, типы, ESLint/FSD, 11 архитектурных тестов, 6 frontend-тестов, форматирование — прошли.
- Тест времени загрузки: быстрый/медленный запрос, ошибка и освобождение таймера при отмене.
- `npm run build`, `git diff --check`, повторные lint/format после окончательных изменений — прошли.
- Встроенный браузер: 320/390px, обе темы, компактная главная и стикеры; горизонтального переполнения нет.
- Черновик мастера: дни выбраны в порядке пятница → понедельник → среда, первым открылся понедельник; два упражнения добавлены вместе; повторения 12–15; копирование веса 25 во все три подхода и отдельная правка второго до 30 дали 25/30/25. Проверочный черновик закрыт без сохранения.
- Быстрые последовательные переходы между вкладками в обеих темах: конечный экран соответствует маршруту, в DOM один main.screen.
- Chrome DevTools MCP не подключился: профиль браузера занят. Браузерные проверки выполнены через CUA во встроенном браузере. Покадровая запись переходов и эмуляция reduced-motion в браузере не выполнялись; отключение пульсации проверено в CSS.
- В используемом аккаунте нет действующей программы: отступ проверен по CSS, создание реальной программы ради проверки не выполнялось.

После проверки пользователь принял результат EGO-45 и разрешил коммит и пуш. Проверки физических устройств остаются отдельной работой.

## Дополнения: вес и порядок упражнений

- GET дня возвращает необязательное `bodyWeightSuggestion`: последнюю фактическую запись текущего пользователя строго раньше даты дня, без ограничения одним предыдущим календарным днём. Старые измерения не копируются в историю автоматически.
- В сегодняшнем дне значение подставляется в поле, «Зафиксировать вес» доступно сразу; подсказка не активирует предупреждение о несохранённых изменениях. Собственная запись дня имеет приоритет. В остальных днях подсказка показана с датой источника и пояснением, что измерение на этот день не сохранено. График по-прежнему использует только фактические записи.
- Шапка упражнения: ручка, название, иконки удаления и сворачивания/разворачивания с доступными названиями и зонами 44px. Нумерация, кнопки Выше/Ниже и общий переключатель удалены по уточнению пользователя.
- При добавлении следующих упражнений предыдущие сворачиваются; последняя добавленная карточка открывается. Можно отдельно разворачивать любые карточки, данные подходов сохраняются при сворачивании и перемещении. Невалидное поле в свёрнутой карточке раскрывается и получает фокус.
- Перетаскивание через Pointer Events и захват указателя: карточка следует за движением, соседние освобождают место, у края страницы работает автопрокрутка; при отпускании обновляются позиции внутри дня. Отмена сбрасывает перемещение. На ручке доступны стрелки клавиатуры. Анимация смещения соседей отключается при reduced-motion.
- Локальный API пересобран и перезапущен для предпросмотра; production не изменялся.
- Четыре Go-теста веса прошли на изолированной PostgreSQL-базе, включая отсутствие автоматического заполнения фактов, выбор последней даты, приватность и явное сохранение подсказанного значения.
- Браузер: сегодняшний день подставил 97 кг из записи 10 октября, кнопка сохранения активна; фактический вес в аккаунте пользователя не сохранялся. Черновик: настройка 25 кг, добавление следующего упражнения, автосворачивание, повторное открытие сохранило 25; реальное перетаскивание указателем поменяло порядок, значение осталось 25. Обе темы, шапка 320px без переполнения. Проверочные черновики закрыты без сохранения. Сенсорный жест на физическом телефоне не проверен.

Последние аннотации: отступ между ручкой и названием увеличен до 12px, номера подходов горизонтально центрированы в первой колонке. Проверки форматирования CSS и `git diff --check` прошли.
