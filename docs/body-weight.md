# Вес пользователя

Запрос пользователя от 10 октября 2026: фиксировать вес на странице текущего дня, смотреть прошлые значения без возможности изменения и открыть график в прогрессе.

Одна приватная запись на дату. Сегодня её можно создать или исправить; прошлые и будущие даты не принимают изменения. Сегодня определяется на сервере по сохранённому часовому поясу пользователя. Вес хранится decimal в кг с точностью до двух знаков; диапазон больше 0 и до 500 кг. Миграция 011 создаёт body_weights, история пользователя и фотографии не затрагиваются.

PUT /api/v1/days/{date}/body-weight использует CSRF, DeviceId, Idempotency-Key и If-Match (0 для создания). GET дня возвращает bodyWeight или null. GET /api/v1/body-weight?from=…&to=… возвращает только историю авторизованного пользователя в порядке дат; диапазон до 366 дней включительно. Изменение веса прошлых дней проверяется сервером, не только отсутствием формы на клиенте. API удаления не добавлен.

В прогрессе доступны виды «Упражнения» и «Вес тела». Для веса доступны 30 дней, 90 дней и год, график, последнее значение, изменение за период и таблица с переходом в день. Вид доступен без завершённых тренировок. График отображает фактические записи, без интерполяции отсутствующих дней в таблице и без рекомендаций по целевому весу.

Проверки: npm run check, Docker production-сборка и миграция; тесты journal/database на изолированной PostgreSQL (приватность, прошлые/будущие даты, If-Match, повторы, формат, порядок истории, просмотр прошлого дня, часовые пояса). В браузере проверены отсутствие формы на прошлом дне, ввод сегодня с запятой, пустые состояния и переключение периода, ширина 320 px и обе темы. Тестовый вес в аккаунт пользователя не сохранялся; заполненный график в его аккаунте не проверялся, поскольку записей ещё нет.

Linear не синхронизирован: подключение отсутствует среди инструментов. 10 октября 2026 пользователь разрешил коммит и пуш этих изменений.

Дополнение EGO-45 (11 октября): GET дня возвращает необязательную `bodyWeightSuggestion` — последнюю запись строго до открытой даты для этого же пользователя. Она используется как начальное значение поля сегодня и подсказка в остальных днях. Измерение возникает только после явного PUT; версия для создания по-прежнему 0, исторические записи и график не заполняются автоматически. Собственный вес дня имеет приоритет над подсказкой.
