# Реализация интерфейса

10 октября 2026: пользователь разрешил последовательную разработку всего интерфейса без промежуточного ревью, с проверкой, коммитом и push каждой задачи.

Порядок в Linear: EGO-38 (основа/главная) → EGO-39 (программа/библиотека) → EGO-40 (тренировка/результат) → EGO-41 (дневник/фото) → EGO-42 (прогресс) → EGO-43 (проверки). Источник дизайна: `design/concept.html`, `design/fitness.css`, `docs/design.md`; данные прототипа в приложение не переносятся. Палитра, Onest и логотип сохраняются.

Основа: FSD, реальные same-origin API, CSRF/версия/idempotency для записи; асинхронные чтения отменяются при смене экрана, данные привязаны к ключу запроса. Детали имеют непрозрачный фон и направленное появление, вкладки переключаются сразу, клонирование DOM не используется.

Production/PWA/push на устройствах, серверная синхронизация и IndexedDB остаются EGO-8/22/27/28/32. Разработка интерфейса не подтверждает эти проверки.

EGO-39: реализованы мастер периода/дней/упражнений/проверки, явное копирование с подтверждением замены и новыми ID, библиотека с поиском/созданием/правкой/архивом, публикация ревизии/архивирование программы. Mutation headers: CSRF, device, version, idempotency с повторным ключом при неизвестном сетевом результате. В реальном браузере 320px созданы упражнение и программа Пн/Сб, выполнено копирование, сохранение и публикация ревизии 2. npm check/build проходят.

EGO-40: подключены запуск по снимку плана, круги подходов, фактические кг/повторения, детали/проверенный источник техники, undo/correct/begin/finish/discard, закреплённый timestamp-отдых, возврат к active с любой вкладки и восстановление с сервера. Исправление завершённого результата сохраняет новую ревизию; доступен просмотр прежних значений. Неизвестный результат команды удерживает исходный commandId для повтора и блокирует следующие команды. Реальный браузер/PostgreSQL: start/complete/undo/reload/begin/finish, три подхода, закрытие отдыха, correction 45 кг × 10 = 450 и сохранённая предыдущая ревизия. Полная офлайн-очередь не входит в задачу.
