# Общая библиотека упражнений

Изменение требований пользователя 10 октября 2026: упражнения добавляются в общую библиотеку всех авторизованных пользователей. Это относится также к ранее добавленным названиям. Автор может менять название и архивировать упражнение; остальные могут выбирать его для собственных программ и тренировок. Личная заметка упражнения доступна только автору. Идентификатор автора не выдаётся.

Программы, история, заметки дня, фотографии и прогресс остаются личными. Завершённые тренировки используют прежние снимки названия и техники. Архив скрывает упражнение из активного выбора, сохраняя существующие ссылки. Одинаковые названия допустимы; автоматического слияния записей нет.

Миграция 009 меняет только связи упражнений с программами и тренировками: ссылка на общий идентификатор вместо пары владельца и идентификатора. Старые миграции не изменяются. API добавляет canEdit; чужие PATCH по-прежнему возвращают 404, личная note в общих ответах пустая.

Дополнительно увеличен отступ над карточкой заметки до 16 px.

Проверки: npm run check прошёл. Интеграционные тесты на реальном PostgreSQL подтвердили чтение общего упражнения вторым пользователем, отсутствие личной заметки и прав изменения, создание программы и тренировки с чужим упражнением, неизменность снимка после переименования и отсутствие чужих фактов прогресса. Полный Go-прогон обнаружил старую ошибку TestSavedProgramSnapshotAndReplacementProtection (completed_set_would_change при неизменной замене); она отдельно воспроизведена на исходном HEAD без изменений этой задачи.

Linear не синхронизирован: подключение отсутствует среди доступных инструментов. Для последующей синхронизации требуется задача проекта «Подход» с критериями: межпользовательская видимость, выбор общего упражнения в программе и тренировке, запрет чужих изменений, приватность заметок и неизменность истории. 10 октября 2026 пользователь разрешил коммит и пуш этих изменений.
