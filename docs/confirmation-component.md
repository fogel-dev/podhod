# Компонент подтверждения

Запрос пользователя от 10 октября 2026: заменить системные подтверждения действий компонентом приложения.

Общий ConfirmationHost показывает нижнюю панель с текстом действия, кнопками «Отмена» и «Подтвердить». Закрытие крестиком, Escape и нажатием на фон равносильно отмене; начальный фокус на отмене. Асинхронный confirmAction разрешается после ответа, повторный запрос не заменяет активную панель. Заменены все 15 вызовов window.confirm: заметки, фотографии, программа, библиотека, расписание, тренировка и навигация из несохранённого черновика. При отмене возврата через историю адрес восстанавливается, при согласии переход повторяется без второго подтверждения.

Предупреждение beforeunload при закрытии или перезагрузке вкладки сохраняется системным: браузер не позволяет показывать React-компонент в этом сценарии.

Проверки: npm run check, тест разрешения и отмены подтверждения и защиты от повторных запросов, Docker-сборка. В браузере проверены отмена закрытия заметки без потери текста, подтверждение закрытия, возврат из черновика программы с отменой и согласием, переход во вкладку с подтверждением и ширина 320 px. Проверочные данные не сохранены.

Linear не синхронизирован: инструменты подключения отсутствуют. 10 октября 2026 пользователь разрешил коммит и пуш этих изменений.
